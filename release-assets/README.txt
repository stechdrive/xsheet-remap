xsheet-remap 配布物の使い分け
================================

■ xsheet-remap.exe
タイムシート編集と素材登録を統合したアプリです。
紙シート読込、タイミング編集、素材管理、音声編集、テンプレート編集、各種出力をまとめて行えます。
「書き出し」→「CLIPを作成」で、画像とタイムラインを登録したCLIPを直接保存します。
新規設定から作成するか、会社・作品のCLIPテンプレートを選択できます。
画像がなくても空セルとタイムラインを作成できます。
旧Editorで保存した.xsrも開けます。

■ xsheet-template.exe
シートテンプレート作成アプリです。
参照画像、ACTION・SOUND・CELL・CAMERA領域、情報欄、補正基準枠を編集して保存します。

■ xsheet-corrector.exe
シート画像補正アプリです。
ダブルクリックすると、補正結果を確認しながら処理できます。
画像やカットフォルダをこのEXEへドロップすると、バッチモードで自動PSD出力を開始します。

CLIPの画像サイズ
----------------
登録画像は同じピクセル寸法に揃えてください。等倍で中央配置します。
既定では大きい画像に合わせて必要な方向だけキャンバスを拡張し、小さくしません。
位置合わせで増えた縁を切る場合は「キャンバスサイズを固定」を選びます。
保存前に表示される四辺の切り取り量を確認してください。

重要
----
・ZIP全体を展開してから使用してください。
・Windowsの「すべて展開」で作成されたフォルダの直下に、各EXEと同梱フォルダが展開されます。
・旧ImporterとPythonランタイムは不要になりました。
・作業を続けるための保存は.xsr、クリスタへ渡す場合は.clipを使用します。
・詳しい操作と事前準備は、各アプリ内のヘルプを確認してください。

Windows SmartScreenが表示されたとき
----------------------------------
この配布物はコード署名されていないため、初回起動時にSmartScreenが表示されます。

1. GitHub ReleasesからダウンロードしたZIPを右クリックし、「プロパティ」を開きます。
2. 「全般」の下部に「許可する」または「ブロックの解除」があればチェックして「適用」を押します。
3. その後、ZIP全体を展開します。
4. 起動時に「WindowsによってPCが保護されました」と表示されたら、「詳細情報」を押します。
5. 表示されたファイル名を確認し、「実行」を押します。

この操作は、次の公式GitHub Releaseから取得したファイルにだけ行ってください。
https://github.com/stechdrive/xsheet-remap/releases/tag/latest

SmartScreenやWindowsのセキュリティ機能を全体で無効にする必要はありません。
