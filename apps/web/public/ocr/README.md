# OCR Runtime Assets

The bundled OCR runtime uses these third-party components:

- PaddleOCR.js: Apache-2.0
- PP-OCRv5 mobile detection and recognition models: Apache-2.0
- ONNX Runtime Web: MIT

The model archives are the official PP-OCRv5 ONNX inference artifacts. Their
embedded model cards declare the Apache-2.0 license. See the repository root
`THIRD_PARTY_NOTICES.md` for the release notice summary.
