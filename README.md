# xsheet-remap

紙とデジタル、作画と撮影をつなぐタイムシート。

xsheet-remapは、ブラウザとWindowsで使える、アニメ制作のためのタイムシートツールです。

使い慣れた6秒シートと連続表示を行き来しながら、セルのタイミング、柔軟なカメラ指示、手書き・テキストメモをまとめて編集できます。対象に結びつけたメモは、表示様式に合わせて対応する位置へ追従します。

セリフ音声は録音・読み込みから編集まで対応。実際に再生して間やテンポを確かめ、発話区間の自動検出を利用してタイムシートのSOUND指示を作成できます。

紙シートの補正、絵とタイムシートを確認しながらのクリスタへの素材登録、After Effectsへのタイミング受け渡しにも対応。独自テンプレートやレイヤーPSD・XDTS出力を使い、現場の様式や後工程に合わせてデータを渡せます。

- [ブラウザ版を開く（GitHub Pages）](https://stechdrive.github.io/xsheet-remap/)
- [Windows版をダウンロード（GitHub Releases）](https://github.com/stechdrive/xsheet-remap/releases/tag/latest)

## できること

### 1. デジタルタイムシートを作る

現場で使われてきた「24fps・6秒で1枚」のA3タイムシート表示と、尺全体を縦方向へ連続してスクロールできるデジタル表示を切り替えられます。

ACTION、CELL、SOUND、CAMERA、カット情報を入力し、タイムライン上の指示や、手書き・テキストによるメモを追加できます。

紙とデジタルで表示を切り替えても入力内容は失われません。MEMO欄など対象を指定して書いた手書きメモは、表示様式に合わせて対応する欄へ追従します。

#### 原画の指示から動画用のセル番号を作る

原画のキーには丸囲み、参考セルには△囲みを付けて記入できます。ACTION欄の原画番号と中割記号から、CELL欄へ1からの連番を自動で割り付けられます。同じ原画の再使用や逆方向の中割に対応し、丸囲み・△囲みも引き継ぎます。

CELL欄に仮表示された結果を確認してから確定でき、原画の指示を動画・撮影用のセル番号へ整理する作業に使えます。

#### セリフの間とテンポを確認してSOUND指示を作る

xsheet-remapでは、セリフをその場で録音したり、収録済みの音声ファイルを読み込んだりできます。

音声からセリフが発話されている区間を自動で認識します。録音した音声クリップの位置や範囲を簡単に編集し、実際に再生しながらセリフの間やテンポを確認したうえで、必要な区間をタイムシートのSOUND指示として反映できます。

音声タイムラインでは、クリップ全体をドラッグして移動し、左右の端をドラッグしてトリムします。`V`で選択、`C`で分割、`R`で範囲選択へ切り替え、`Ctrl+K`で再生ヘッド位置を分割できます。「＋トラック」で必要なトラックを追加し、名前・順序・ミュート・ソロ・ロックを設定できます。

金色のSOUND帯は、キャストへ伝える収録区間です。音声より早く始めたり、長く取ったりできます。「前後の余白を保って追従」と「収録区間を固定」を選べ、クリップを分割してもSOUND指示は分割されません。音声を削除した場合も指示を残します。

CLIPの音声レイヤーは個別または一括で音声トラックへ取り込めます。編集した配置・分割・トリム・ミュートは「CLIPを作成」で書き戻せます。WAV・MP3の素材データは保持し、未対応の音量変化などを含む音声は取り込まず元CLIP内に残します。ソロとロックはアプリ内の作業設定です。

録音音声、編集したクリップ、認識したセリフ区間、SOUND指示との対応は.xsrへまとめて保存されます。

#### After Effectsへタイミングを渡す

セル画像を1セル1枚の画像シーケンスとしてAfter Effectsへ読み込み、ACTIONまたはCELLのタイミングを連番レイヤーのタイムリマップへ反映できます。

1列だけコピーして貼り付ける場合は、次の手順で適用します。

1. コンポジションと連番のフレームレートをタイムシートと同じ値（通常24fps）にします。列見出しの「AE用データをコピー」でAEの表示言語を選びます。
2. AEで対象の連番レイヤーを選び、現在時刻を0フレームにして貼り付けます。AE 2026では貼り付けだけでタイムリマップが有効になり、先頭と値の変化点にキーが入ります。
3. 貼り付けたタイムリマップの全キーを選び、「アニメーション」→「停止したキーフレームの切り替え」で停止（HOLD）にします。カラセルがある列は、ブラインドの「変換終了」の全キーもHOLDにします。テキストの貼り付けではHOLD設定を渡せません。
4. レイヤー尺は自動では延びません。対象レイヤーを選び、カットの最終フレームでWindowsは`Alt+]`、macOSは`Option+]`を押してアウトポイントを延長します。

複数列のJSX書き出しとWindows版の直接送信では、割り当てた連番のフレームレートを取得し、タイムリマップの有効化・変化点へのHOLDキー設定・レイヤーの延長を自動で行います。

#### タイムシートを書き出す

完成したタイムシートは、用途に合わせて画像として書き出せます。

- PNG・JPG：確認や共有に使いやすい一枚の画像
- PSD：紙シート、テンプレート、入力内容、手書きメモなどを分けたレイヤー画像

PSDでは必要なレイヤーを保ったまま渡せるため、画像編集ソフトで表示、修正、加筆を続けられます。他のタイムシート対応ソフトへ渡す場合はXDTSを使用できます。

### 2. 紙タイムシートと紙作画素材をデジタルの後工程へつなぐ

#### 紙タイムシートを書き直せるPSDにする

紙タイムシートは、そのままのスキャン画像では後工程で文字や線を書き直したり、不要な指示を消したりするのが困難です。

xsheet-correctorは、設定済みのテンプレートを基準に、同じ様式のタイムシート画像の傾きや位置のずれを補正します。同じA3サイズでも、罫線の配置が異なれば、その様式に合うテンプレートが必要です。

各社独自のタイムシートを使う場合は、先にRemapの「テンプレートを作成・編集」でその様式の参照画像と補正基準枠を設定したテンプレートを作成し、JSONとして保存します。CorrectorでそのJSONを読み込んで「テンプレ」に選択してから、画像を補正してください。

補正済みのスキャン画像、テンプレート罫線、白地を別々のレイヤーにしたPSDとして保存するため、画像編集ソフト上でタイムシートの修正、消し込み、加筆を行いやすくなります。

#### 6秒タイムシート上でクリスタのタイムラインを組み立てる

xsheet-remapでは、スキャンした作画素材と使い慣れた6秒タイムシートを同じ画面で確認できます。

画面上部で「シート編集」と「CLIP組み立て」を切り替えます。シート編集では番号・タイミング・メモ・音声を編集し、CLIP組み立てでは右のレイヤーツリーで素材を扱います。途中で切り替えても、シート、下敷き、音声、レイヤー構造とUndo履歴を保持します。

レイヤーツリーへ画像を一括追加し、セルをシート上の該当するマスへドラッグします。ツリーの素材は所属するアニメーションフォルダーの工程に登録されます。OSから直接シートへドロップする画像は、上部の「新規画像の登録先」を使用します。既存番号のコマやその継続区間へのドロップでは、工程別の登録状況を確認し、その番号への登録・差し替え、または新しい番号としての配置を選びます。ツリーの選択だけで新規画像の登録先は変わりません。

新規作業では既定のフォルダー構造を使います。「読み込み」→「CLIPを読み込む」、またはCLIPファイル1件のドラッグ＆ドロップで既存のCLIPを開けます。現在のシート、下敷き、Undo履歴をリセットし、元のレイヤー・画像・タイムラインを保持して作業を始めます。未保存の変更がある場合は開く前に確認します。タイムラインのないCLIPも開けます。

紙シートの列数を超えるアニメーションフォルダーは、読み込み先に選んだACTION欄またはCELL欄の右端へ追加セル列として配置します。追加列を移動した位置は、XSRの保存・再読込でも保持します。

- 右ペインで通常フォルダー、アニメーションフォルダー、セルを作成し、移動・改名・表示・不透明度・合成モードを編集できます。
- 工程とセル列の登録先はアニメーションフォルダーを選んで指定します。セル内の画像登録先も、例えば「作監」のように指定できます。
- BG・BOOK・メモの素材は通常フォルダーにも保管できます。紙面上の表示フラグとレイヤーの保存先は独立しています。
- クイックルックで画像や保存済みのフォルダー合成を確認できます。合成画像がないフォルダーは中の画像を個別表示します。
- 「登録先工程の素材だけ表示」は上部の登録先工程に合わせて表示だけを絞ります。レイヤーの目玉や書き出し内容は変わりません。

「書き出し」→「CLIPを作成」で、レイヤー構造とタイミングを含むCLIPを保存します。既存CLIPの未編集画像・未編集タイムラインは維持します。画像編集やCSP固有の効果の再描画は行いません。新しい画像は中央配置し、用紙外を切り捨てるため、新規作成では必要なキャンバスサイズを指定してください。

複数タイムラインは、セルを共有する兼用カットとしてシートへ取り込めます。カットごとのFPS・尺・セル指定を保持します。再生範囲外のセル指定は前後のダミーコマへ取り込み、非表示にしても位置は保存します。

既存CLIPの工程別タイミングは独立して保持します。中央上部の「編集しているタイミング」で対象を切り替えます。「シート編集」に切り替えても工程のタイミングを統合・同期しません。

既存の同名セルは保持し、同じアニメーションフォルダー内では下段のセルを採用します。新しい同名セルの追加・改名や、同名セルの採用対象を変える並べ替えは止めます。通常フォルダー内の同名素材は許容します。

シートの記載とCLIPのセル名は別々です。長い記載は欄内へ縮小し、収まらない部分は「…」で省略します。「一括リネーム」の「シート記載」で先頭ゼロの除去や初出順の連番を確認して適用でき、一度のUndoで戻せます。

作業途中は .xsr に保存します。元CLIPと新しく追加した画像も含むため、保存した作業を再開できます。PNG・JPEGなどブラウザーで表示できる画像を使用してください。

### 3. スタジオごとのタイムシートデザインに対応する

Remapのメニュー「テンプレートを作成・編集…」では、スタジオや作品ごとに異なるタイムシートの罫線、情報欄、列名、配色をテンプレートとして作成できます。

A3標準やデジタル標準を土台に調整するほか、実際の紙タイムシート画像を参照しながら配置を合わせることもできます。専用のウィンドウ（ブラウザ版では別タブ）でテンプレートだけを作成でき、起動時の「下書きを復元」から未保存の作業を再開できます。Windows版は旧Templateと同じ下書き保存先を使います。

「テンプレートJSONを保存」は受け渡し用のJSONを書き出します。シートへ反映するには、RemapでそのJSONを読み込むか、シート側の「テンプレ」画面で「プロジェクトへ反映」を押してください。JSON保存だけでは編集中のシートを変更しません。Correctorの「テンプレートを作成・編集」からも専用画面を開けます。保存後はCorrectorの「テンプレJSONを読み込み」でJSONを選びます。

作成したテンプレートはRemapで使用でき、スタジオの様式を保ったままタイムシート入力、手書きメモ、紙画像補正、PNG・JPG・レイヤーPSD出力を行えます。参照画像と補正基準枠を設定した紙用テンプレートはCorrectorにも読み込めます。

## 2つのアプリ

| アプリ | 役割 |
| --- | --- |
| `xsheet-remap.exe` | デジタルタイムシート、素材対応、音声・手書きメモ、AE連携、CLIP作成、テンプレート作成・編集をまとめて扱う |
| `xsheet-corrector.exe` | 紙タイムシートの傾きやずれを補正し、編集しやすいレイヤーPSDにする |

## 使ってみる

### ブラウザ版

[GitHub Pagesのxsheet-remap](https://stechdrive.github.io/xsheet-remap/)を開くと、Remapの「シート編集」が起動します。「CLIP組み立て」へ切り替えると、右側のレイヤーツリーで素材やCLIPを扱えます。従来の`?app=remap`付きURLからも同じRemapを開けます。

デジタルタイムシート、表示切り替え、手書きメモ、セリフ音声の録音・編集と発話区間の自動認識、AE用データのコピー、PNG・JPG・PSD出力、.xsrの読込と保存を利用できます。

CLIPの読み込み・保存・再出力はブラウザ版でも利用できます。素材画像はブラウザへ読み込んでください。起動中のAfter Effectsへの直接送信など、Windows固有の機能にはデスクトップ版が必要です。

### Windows版

[GitHub Releasesのlatest](https://github.com/stechdrive/xsheet-remap/releases/tag/latest)から`xsheet-remap.zip`をダウンロードし、ZIP全体を展開します。インストールは不要です。

Editorの編集機能とTemplateのテンプレート作成機能は`xsheet-remap.exe`へ統合されました。以前の`.xsr`とテンプレートJSONをそのまま利用できます。Correctorの「テンプレートを作成・編集」も、同じフォルダーのRemapを開きます。

テンプレート専用のショートカットを作る場合は、Remapのリンク先の末尾に` --template`を付けると、シートを開かずにテンプレート作成の開始画面を直接開けます。

## 基本の流れ

### デジタルタイムシートを作る

1. `xsheet-remap.exe`またはブラウザ版を開きます。
2. カット情報と尺を入力します。
3. A3標準またはデジタル標準を選びます。
4. ACTION・CELLへタイミングを入力します。
5. 必要に応じてSOUND・CAMERA・手書きメモを追加します。
6. セリフ音声を使う場合は、録音したクリップを編集して間とテンポを確認し、認識された区間からSOUND指示を作ります。
7. .xsrへ保存するか、PNG・JPG・PSD・XDTS・AE用データとして受け渡します。

### 紙作画素材をクリスタへ登録する

1. 必要に応じてCorrectorで紙タイムシートの傾きやずれを補正し、PSDにします。
2. Remapで紙タイムシートとスキャン済みの作画素材を開きます。
3. 素材画像を6秒タイムシート上の該当するマスへドラッグします。
4. セル名、工程、重ね順を確認し、「CLIPを作成」を開きます。
5. キャンバスサイズと対象カットを確認して保存します。既存のCLIPを使う場合は、作業を始める前に読み込んでおきます。

紙作画素材は、登録前にタップ穴を基準とした位置合わせを済ませておくと、クリスタへ登録した際の位置が安定します。
